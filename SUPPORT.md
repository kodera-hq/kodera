# Support

Status: Active

## Community & Self-Hosted Support

- **Questions, Self-Host Setup & Ideas:** Use [GitHub Discussions](https://github.com/kodera-hq/kodera/discussions).
- **Reproducible Bugs:** Open a [Bug Report Issue](https://github.com/kodera-hq/kodera/issues/new/choose) with version, OS, and minimal reproduction steps.
- **Security Vulnerabilities:** Never report publicly — follow [`SECURITY.md`](./SECURITY.md) (`support@kodera.io` or GitHub Private Vulnerability Reporting).

## Managed Cloud, Autopilot & Enterprise SLA

Organisations running mission-critical communications on **Kodera Cloud**, **Kodera Autopilot (Managed Self-Host)**, or **Kodera Enterprise** receive priority engineering support, uptime SLAs, and dedicated onboarding via **[kodera.io](https://kodera.io)** (`support@kodera.io`).
