# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in Kodera for iOS, **please do not open a public issue**.

Instead, report it responsibly via email:

📧 **support@kodera.io**

### What to Include

- Description of the vulnerability
- Steps to reproduce
- Potential impact assessment
- Suggested fix (if any)

### Response Timeline

| Action | Timeline |
|--------|----------|
| Acknowledgment | Within 48 hours |
| Initial assessment | Within 5 business days |
| Fix & disclosure | Coordinated with reporter |

## Scope

The following are in scope for security reports:

- Application source code
- Authentication and authorization flows
- API endpoints and data handling
- Third-party integration security
- Infrastructure configuration

## Out of Scope

- Issues solely in third-party products, outside this client's integration
- Denial of service attacks
- Social engineering
- Issues requiring physical device access

## Acknowledgment

We appreciate responsible disclosure and will credit researchers in our changelog (unless anonymity is requested).
