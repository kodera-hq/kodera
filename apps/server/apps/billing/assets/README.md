# PDF output color profile

Status: Active

`sRGB2014.icc` is the unmodified 3024-byte International Color Consortium profile.
SHA-256: `384b832de3412066743b52a75ee906b6fb9fb8d9e09e936fc2c43223815c6e0a`.

The [ICC profile registry](https://registry.color.org/rgb-registry/srgbprofiles) provides this
profile under its [general profile license](https://registry.color.org/profile-library/), which
permits copying, distribution and embedding. The original copyright/identification tags are
retained. Copyright International Color Consortium.

The ICC download server refused automated access during source preparation. These identical
profile bytes were obtained from the official `weasyprint-70.0-py3-none-any.whl` archive on PyPI,
whose SHA-256 is `5043e55e38d2a2af2b2b871e869697b1f65dad5f8b4a3677961d04ceacf9c5fe`.
The runtime uses the checked-in profile and never downloads a color asset.
