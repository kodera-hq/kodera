# Local workspace preferences and Docs models

Status: Implemented local seams; remote authority and persistence are unprovisioned.

`DesktopWorkspaceSession` retains an organisation-scoped theme, optional profile and at most32 local Docs pads. Clear, Drop and successful or failed organisation replacement discard those values. Theme mode defaults to black. Selecting a mode discards a previously imported custom palette; importing a theme leaves sound preferences unchanged.

The native `kodera-theme:v1:` contract uses standard padded RFC4648 base64 and exactly these JSON fields, in canonical encoder order: `v`, `id`, `name`, `author`, `baseMode`, `tokens`. Version is integer1; mode is `light`, `dark` or `black`. Tokens contain exactly `--c-page`, `--c-surface`, `--c-sunken`, `--c-action`, `--c-ink`, in that order, with canonical `rgb(r, g, b)` channels0–255. Whole code size is at most2048 UTF-8 bytes. Decoding rejects surrounding/embedded base64 whitespace, alternate alphabets, nonzero padding bits, invalid UTF-8, duplicate decoded JSON keys, unknown fields, nested structures and invalid metadata. IDs use lowercase ASCII letters/digits/hyphens1–64; names/authors use trimmed1–64 UTF-8 bytes. Metadata rejects Unicode line/paragraph separators, controls and the pinned Unicode15.1 format-control set, without Unicode normalization. This deliberately strict native grammar does not silently accept older hex/sound-pack envelopes. The existing Web v1 encoder omits `id`, so its codes are refused rather than inventing an identity; shared fixtures qualify the three native codecs and preset RGB values only.

The four curated IDs are `preset-real-black-oled`, `preset-cobalt-polaire`, `preset-terminal-ambre`, `preset-foret-souveraine`. RGB values follow the curated Web definitions; metadata names remain English. The immutable monogram background remains `[0,0,0]` / `#000000` regardless of selected theme.

Profiles require canonical non-nil UUID correlation IDs, lowercase ASCII handles1–32, trimmed display/role text1–64 UTF-8 bytes, optional status text1–128 bytes and optional emoji text1–16 bytes. These byte caps are conservative subsets of the brief's character limits. A local role field is editable preview metadata, never proof of membership or administrator authority. The pure IAM evaluator requires read access before any other permission; polling additionally requires write, connector management requires manage, and voice joining requires a voice channel. There is no rank bypass or service policy mutation.

Docs documents begin at revision1, bound title to120 UTF-8 bytes and Markdown body to65,536 UTF-8 bytes, and bound ASCII pad IDs to128 bytes and channel/actor correlation IDs to255 bytes. Bodies reject controls/format characters except carriage return, line feed and tab. Updates validate before replacing content and refuse revision overflow. Frontmatter strings are quoted/escaped and Markdown remains literal; no HTML renderer, collaboration transport or persistence is provided. Public malformed document values export an empty string rather than unbounded or injected metadata.

Six new operations retain the existing flat `command` schema and may alternatively use `op`: `set_theme_mode`, `import_shareable_theme`, `export_shareable_theme`, `update_user_profile`, `evaluate_channel_iam`, `save_docs_pad`. Both forms require the active canonical `organisation_id`. Supplying both discriminator fields is refused; `op` cannot invoke older commands. New fields are `mode`, `code`, profile `user_id`/`display_name`/`handle`/`role_title`/`presence`/`rank` plus optional `status_emoji`/`status_text`, IAM `channel_id`/`rank`, and Docs `pad_id`/`channel_id`/`title`/`markdown_body`/`actor`. Unknown/duplicate fields are refused. IAM JSON evaluates a fixed local text-channel preview policy; typed callers can evaluate an explicit policy. Neither result grants service authority.

The unchanged16,384-byte raw JSON budget limits IPC document updates below the model's64KiB bound; oversized requests refuse before parsing or side effects. Full-size local model updates use the typed API. The largest exact schema has ten flat fields; arrays remain at most ten scalar elements. Request diagnostics are fully redacted and errors carry no raw input. These methods are not registered JavaScript IPC or response wire serialization.

The desktop WebView contract enforces `default-src 'self'`, local/data/blob images, explicit path-scoped HTTPS/WSS `connect-src` origins (`WEB-ADR-0012`), and zero `'unsafe-eval'`. Inline styles remain required by the shared web UI (microphone meters and positioning); scripts never allow inline evaluation. The `kodera-desktop` host binary runs local self-checks (`--self-check`), deep-link admission (`--deep-link`), and bounded stdio JSON IPC (`--ipc-stdio`).
