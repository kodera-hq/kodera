# Connector marks

Status: Active

Self-hosted SVG geometry identifies the named integrations. Trademark ownership remains with each provider; inclusion does not imply endorsement. SVGL mirrors publisher marks; source revisions are pinned below. No runtime network fetch or CSS inversion is used. GitHub and Sentry use white SVG backing; the official white Frame.io wordmark uses black backing to retain contrast in every theme. Generic webhook, documents and monitoring glyphs are original UI symbols.
